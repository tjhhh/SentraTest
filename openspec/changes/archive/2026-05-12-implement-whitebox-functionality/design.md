## Context

The system needs to analyze source code and execute tests. Currently, the backend is a skeleton and the frontend is mocked. We need to integrate Gemini for intelligent analysis and Playwright for reliable execution.

## Goals / Non-Goals

**Goals:**
- Implement `POST /api/whitebox/generate` to produce Playwright scripts using Gemini.
- Implement `POST /api/whitebox/run` to execute scripts and stream output.
- Update Frontend to use these endpoints.
- Ensure the backend can run Playwright.

**Non-Goals:**
- Multi-user isolation (standard process isolation for now).
- Persistent storage for generated scripts (stored in memory or temp files).
- Support for languages other than JavaScript/Node.js.

## Decisions

### 1. Gemini for Code Analysis
We will use `@google/generative-ai` to interface with Gemini. Gemini is better suited for understanding logical paths in code than regex or simple AST traversal for this hackathon context.
- **Alternatives**: Using `acorn` or `babel-parser` for AST analysis. While more precise for coverage, it's more complex to implement "human-readable" test scenarios and assertions from scratch.

### 2. Execution via Child Process
We will use `child_process.spawn` to run `playwright test`. This allows us to capture stdout/stderr in real-time.
- **Alternatives**: Playwright API (`chromium.launch`). Harder to capture full CLI output format which users expect from a "terminal".

### 3. File-based Execution
Generated scripts will be written to a temporary file (e.g., `temp-test.spec.js`) before execution.
- **Rationale**: Playwright Runner works best with files.

## Risks / Trade-offs

- **[Risk]** Code Injection via generated scripts → **Mitigation**: Scripts are generated by Gemini based on user input but executed in a backend process. We will limit the scope of the script (no network access if possible, though Playwright usually needs it).
- **[Risk]** Gemini Hallucinations → **Mitigation**: We will prompt Gemini to produce strictly valid JavaScript/Playwright code.
- **[Risk]** Missing Playwright dependencies in Docker → **Mitigation**: Update `backend/Dockerfile` to install Playwright browsers and dependencies.
